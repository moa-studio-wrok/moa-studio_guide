01

개요

고객이 상품을 선택하는 흐름을 먼저 이해해 주세요.

엘씨엘 쇼핑몰의 상품 상세페이지는 고객이 카드 형태로 상품을 선택하고, 필요한 항목을 순서대로 설정하는 방식입니다.

STEP 1옵션 카드 선택
›
STEP 2맛 선택
›
STEP 3체험팩 선택 · 동의 팝업 (해당 옵션만)
상품 유형화면 진행운영 참고
맛 선택 상품STEP 1 → STEP 2 (→ STEP 3 팝업)맛 선택 정보와 이미지 배너가 필요합니다. STEP 3 팝업은 옵션명과 일치하는 추가옵션 배너가 있을 때만 표시됩니다.
맛 없는 단일 옵션 상품STEP 1 (→ STEP 3 팝업)맛 선택 단계(STEP 2)는 표시되지 않습니다. STEP 3 팝업은 옵션명과 일치하는 추가옵션 배너가 있을 때만 표시됩니다.
옵션 없는 단품카드 없음옵션 카드 없이 ‘선택된 상품’ 영역에 단품 1개가 기본 표시됩니다.
공통 화면

맛 선택 상품과 맛 없는 단일 옵션 상품은 카드 화면을 사용하고, 옵션 없는 단품은 카드 없이 ‘선택된 상품’ 영역만 표시됩니다. 세 유형 모두 ‘선택된 상품’ 영역에서 수량을 조절합니다. 체험팩·팝업의 상품별 노출 조건은 [확인 필요] 입니다.

02

운영 구조

무엇을 어디에서 수정하는지 한 장으로 확인할 수 있습니다.

관리 항목관리 위치운영 방법
맛 목록상품관리 > 상품수정 > 기본정보 > 추가항목‘맛 선택’ 칸에 맛 이름을 입력합니다.
맛 이미지배너매니저 > 맛 이미지 배너맛 이름과 똑같은 이름으로 이미지를 등록하고 여러 상품에서 공유합니다.
체험팩 · 동의 팝업배너매니저 > 추가옵션 배너STEP 3의 배너 콘텐츠를 관리합니다.
선택 카드 · 수량고객이 보는 상품 상세페이지상품의 등록 상태에 따라 표시되므로 저장 후 동작을 확인합니다.
핵심 원칙 — 맛 이름당 배너는 1개만 등록

‘초코맛’을 사용하는 상품이 여러 개여도 이미지 배너는 한 번만 등록합니다. 상품마다 중복 등록하지 않아 배너 50개 제한을 피하는 데 도움이 됩니다.

03

상품 등록 방법

실제 관리자 화면을 보면서 순서대로 설정해 주세요.

3-1. 맛 선택 상품 등록

상품 수정 화면 접속

등록된 상품 중 수정할 상품을 열고 기본정보의 추가항목을 확인합니다.

상품관리 > 상품수정 > 기본정보 > 추가항목

‘맛 선택’ 칸에 맛 이름 입력

쉼표(,)로 구분해서 입력합니다. 추가항목 칸은 최대 250자이므로 이 안에서 입력해 주세요. 배너 이름과 글자 그대로 같아야 합니다. (띄어쓰기·대소문자 포함)

입력 예시 · 쉼표로 구분초코맛, 곡물맛, 흑임자맛, 옥수수맛, 쿠키앤크림맛

동일한 맛 이름을 반복 입력해도 한 번만 처리됩니다.

추가입력옵션 설정

맛 선택 상품에는 추가입력옵션(주문할 때 고객의 선택값을 받는 항목)을 2개 사용으로 설정합니다. 고객이 고른 맛은 ‘상품 구성’에, 체험팩 선택값은 ‘추가 옵션’에 자동으로 입력됩니다. 고객이 직접 입력하는 칸이 아닙니다.

추가옵션명필수 여부최대 글자 수역할
상품 구성필수항목200자고객이 고른 맛이 자동 입력됩니다.
추가 옵션선택항목200자STEP 3 체험팩 선택값이 자동 입력됩니다.
실제 화면 03 · 추가입력옵션 설정제공 이미지 · 빨간 테두리 참고
상품 수정 > 옵션/재고 > 추가입력 옵션에서 ‘상품 구성’(필수항목, 200자)과 ‘추가 옵션’(선택항목, 200자)을 사용으로 설정합니다.

저장 후 실제 상품에서 확인

저장한 뒤 고객이 보는 상세페이지에서 맛 목록이 잘 나타나는지 확인합니다. 반영까지 잠시 걸릴 수 있습니다.

3-2. 맛 선택이 없는 상품

항목운영 방법
‘맛 선택’ 추가항목비워 둡니다.
추가입력옵션맛 선택이 없는 상품은 ‘상품 구성’ 등을 별도로 등록하지 않아도 됩니다.
STEP 2 맛 선택표시되지 않습니다.
옵션 없는 단품‘선택된 상품’ 영역에 수량 1개가 기본 표시됩니다.

3-3. 맛 이미지가 표시되는 규칙

기준표시 방식
맛 이름 일치등록한 맛 이름과 같은 이름의 배너 이미지를 사용합니다.
상품에 연결된 배너 존재같은 상품에 연결된 배너가 있으면 해당 이미지를 우선 사용합니다.
이미지를 찾을 수 없음이미지 없이 표시합니다.
기존 방식과 함께 운영할 때 주의

‘맛 선택’ 칸이 비어 있는 기존 상품은 상품 링크가 연결된 배너를 사용합니다. 모든 맛 선택 상품에 맛 이름을 먼저 입력한 뒤 중복 배너를 정리해야 이미지 누락을 예방할 수 있습니다.

04

배너매니저 등록 방법

이미지는 맛 이름을 기준으로 함께 사용합니다.

4-1. 맛 이미지 배너 등록

맛 이미지 배너 그룹 열기

배너매니저에서 맛 이미지 배너 그룹을 선택합니다.

배너매니저 > 맛 이미지 배너

‘이미지 추가’로 배너 등록

배너 이름은 상품의 맛 선택값과 정확히 같게 입력합니다. 상품 링크는 연결하지 않아도 됩니다.

배너 입력 항목운영 방법
배너 이름상품에 입력한 맛 이름 그대로 등록합니다.
이미지해당 맛에 맞는 이미지를 등록합니다.
링크 URL선택 사항입니다. 이미지 공유를 위해 필수로 입력하지 않습니다.
표시 기간운영 목적에 맞게 설정합니다.
이름 일치 예시상품 ‘맛 선택’ = 초코맛   |   배너 이름 = 초코맛 일치

4-2. 중복 배너 정리 순서

  1. 해당 맛을 사용하는 모든 상품에 ‘맛 선택’이 입력되어 있는지 확인합니다.
  2. 모든 상품을 저장한 후 맛 이미지 표시 상태를 확인합니다.
  3. 같은 맛 이름으로 중복 등록된 배너를 정리합니다.
  4. 관련 상품을 다시 열어 이미지가 계속 보이는지 확인합니다.
배너부터 먼저 삭제하지 마세요.

기존 상품 중에는 상품 링크 방식으로 이미지를 불러오는 상품이 있을 수 있습니다.

4-3. 체험팩 · 동의 팝업 배너

STEP 3 팝업에서 사용하는 콘텐츠는 맛 이미지와 별도 그룹으로 관리합니다. 고객이 옵션 카드를 선택했을 때, 그 옵션명과 같은 이름의 추가옵션 배너(옵션명 항목)가 등록되어 있으면 체험팩 선택 팝업이 나타납니다. 일치하는 배너가 없거나 배너가 꺼져 있으면 팝업 없이 STEP 2에서 선택이 끝납니다.

배너매니저 > 추가옵션 배너

07

문제 해결 · FAQ

오류가 보이면 증상부터 확인해 주세요.

증상가능한 원인조치 방법
맛 이미지가 안 나옵니다.배너 이름 불일치 또는 이미지 배너 미등록상품의 맛 이름과 배너 이름을 글자 단위로 비교하고 이미지 등록 여부를 확인합니다.
맛 목록이 안 나옵니다.‘맛 선택’ 칸이 비었거나 저장되지 않음입력 후 저장하고 새로고침합니다. 반영에 잠시 시간이 걸릴 수 있습니다.
맛 상품인데 맛 선택 없이 단순 옵션처럼 보입니다.‘맛 선택’ 칸이 비어 있고 상품에 연결된 맛 배너도 없음‘맛 선택’ 칸에 맛 이름을 입력하고 저장합니다. 250자를 넘지 않았는지도 확인합니다.
옵션이 숨겨지거나 구매가 안 됩니다.필수 추가입력옵션 설정 문제 가능성추가입력옵션 ‘상품 구성’의 필수 설정과 최대 200자 설정을 확인합니다.
