01

상품 추가이미지

상품 상세페이지와 상품목록에 보이는 이미지를 등록합니다.

상품관리 > 상품수정 > 이미지정보
등록 항목화면에서 쓰이는 곳운영 방법
추가이미지등록상품 상세페이지 이미지 영역PC는 이미지가 세로로 이어서 나열되고, 모바일은 좌우 슬라이드(“1 / N”)로 보입니다. 이미지 추가하기로 최대 20개까지 등록하고, 마우스로 드래그해 순서를 바꿉니다.
이미지등록
(상세 · 목록 · 작은목록 · 축소)		상품목록 · 메인 상품의 썸네일 슬라이드4종 이미지가 순서대로 슬라이드되고 하단에 진행바가 표시됩니다. 같은 이미지로 등록하면 슬라이드에서도 같은 이미지가 보이므로, 이미지마다 다르게 보이려면 ‘개별이미지등록’으로 각각 올려 주세요.
등록 조건

추가이미지는 1MB 이하, gif · png · jpg(jpeg) 형식으로 20개까지 등록할 수 있습니다. 추가이미지가 없는 상품은 대표 이미지 1장만 나옵니다.

상품수정 화면에서 이미지정보 탭 열기

상품관리 > 상품수정에서 해당 상품을 열고 이미지정보 탭으로 이동합니다.

추가이미지등록에서 이미지 추가

이미지 추가하기를 눌러 이미지를 올리고, 드래그로 노출 순서를 정합니다.

저장 후 상세페이지에서 확인

상품수정을 저장한 뒤 상세페이지를 강력 새로고침(Ctrl + F5)해서 PC는 세로 나열, 모바일은 슬라이드로 보이는지 확인합니다.

02

분류 상단 이미지

상품 분류 페이지 맨 위 큰 이미지를 등록합니다.

상품관리 > 분류 관리 > 상품 분류 관리 > 분류꾸미기

분류 선택

상품 분류 관리에서 이미지를 넣을 분류를 선택합니다.

PC쇼핑몰 탭에서 상단 이미지 등록

상단 이미지를 이미지 직접등록으로 선택하고 이미지를 불러옵니다. 최대 3개까지 등록할 수 있고, 파일은 1MB 이하의 gif · png · jpg(jpeg)입니다. 가로 1920px 전후를 권장하며, 화면이 이보다 넓으면 폭 100%로 확대됩니다.

모바일쇼핑몰 탭에서 따로 등록

PC와 모바일은 탭이 따로입니다. 모바일에 보일 이미지는 모바일쇼핑몰 탭에서 한 번 더 등록해 주세요. PC에만 등록하면 모바일에는 이미지가 나오지 않습니다.

하위분류에도 적용 (선택)

하위분류에도 같은 이미지를 쓰려면 ‘하위분류 동시적용’을 체크합니다.

03

메인 추가 영역

메인에 새로 생긴 상품 진열과 배너 영역의 등록 방법입니다.

3-1. 상품 진열 (Best Sellers · New In)

상품관리 > 상품진열 > 메인상품진열
화면 영역연결할 진열 그룹
Best Sellers · Women기존 Best Seller 그룹 (product_listmain_1)
Best Sellers · Menproduct_listmain_2
Best Sellers · Kidsproduct_listmain_3
Best Sellers · Accessoriesproduct_listmain_4
New In (신상품 슬라이드)product_listmain_5

그룹을 연결하지 않은 탭은 비어 보입니다. PC에서 상품이 6개 이상이면 화살표로 슬라이드되고, 5개 이하는 고정으로 보입니다. 모바일은 손가락으로 밀어 넘깁니다.

탭 이름(카테고리) 변경 방법

탭에 보이는 이름(Women · Men · Kids · Accessories)은 스마트디자인 편집창에서 직접 바꿀 수 있습니다.

스마트디자인 편집창 > 주요화면 > 메인화면(index.html) > tab_product.html

메인화면에서 tab_product.html 열기

메인화면(index.html)에서 Best Seller 상품 리스트를 불러오는 줄(빨간 테두리)을 찾습니다. 줄에 적힌 /moa/import/main/tab_product.html 파일을 열어 주세요.

탭 이름(<li>) 수정

tab_product.html에서 빨간 테두리의 <li> 4줄 글자만 원하는 카테고리명으로 바꿉니다. 저장 후 메인을 강력 새로고침(Ctrl + F5)해서 확인합니다.

수정 항목방법
탭 이름<li> 안의 글자만 바꿉니다. 예: <li>Men</li> → <li>Bags</li>
첫 번째 탭의 class="on"그대로 둡니다. 메인에 처음 열려 있는 탭을 정하는 부분입니다.
data-category 값같은 파일 아래쪽 각 탭 상품 영역의 data-category="Women" 등은 구분용 이름이라 화면에는 영향이 없습니다. 헷갈리지 않도록 탭 이름과 같이 바꿔 두면 편합니다.
탭 이름을 바꿔도 상품은 자동으로 바뀌지 않습니다

탭은 이름이 아니라 순서로 상품 그룹과 연결됩니다. 이름을 바꾼 뒤에는 해당 순서의 진열 그룹(메인상품진열 1~4번)에 그 카테고리의 상품을 연결해 주세요. 탭은 4개로 고정이라 개수를 늘리거나 줄이려면 개발 담당자에게 요청해 주세요.

3-3. 등록 순서

배너 카드에서 ‘수정’ 선택

배너매니저에서 해당 배너 카드(예: 메인 어패럴 동영상 컬렉션)의 수정 버튼을 누릅니다.

이미지와 링크 등록

표의 권장 크기와 개수에 맞춰 이미지를 등록하고, 이동할 링크 주소를 입력합니다.

HTML 칸에 문구 입력

화면에 보이는 텍스트는 배너의 HTML 칸에 아래 형식으로 입력합니다. 입력하지 않은 항목은 기본 문구가 보입니다. [ ] 안의 항목명은 수정하지 않고 뒤의 내용만 바꿔 주세요.

Apparel

[타이틀]Apparel
[내용]새로운 어패럴 컬렉션을 만나보세요.<br>기능적이면서도 감각적인 라인을 선보입니다.
[버튼]shop now
[영상]AsMbXywVVZY

[영상]을 입력하면 배경 이미지 가운데에 유튜브 영상이 재생되고, 비워 두면 배경 이미지만 나옵니다. [영상타이틀] · [영상내용]은 영상 위에 표시되는 문구입니다.

영상 입력 5가지 형식 — ① 영상 ID(권장) ② 단축 URL youtu.be/영상ID ③ 일반 URL youtube.com/watch?v=영상ID ④ 쇼츠 URL youtube.com/shorts/영상ID ⑤ iframe 삽입 코드(embed)

인스타그램 · 푸터 SNS 아이콘

영역등록 방법
인스타그램이미지 배너로 등록합니다. 기존 방식(SnapWidget iframe)은 더 이상 사용하지 않으므로 기존 배너 안의 iframe 내용은 지우고 같은 크기의 정사각형 이미지로 교체해 주세요. PC는 6열 × 2행, 모바일은 3열 × 2행으로 정렬됩니다.
푸터 SNS 아이콘페이스북·인스타그램·카카오 등 아이콘 이미지를 등록하고 각 SNS 주소를 링크로 입력합니다. 기존 텍스트 링크 배너가 남아 있으면 이미지로 교체해 주세요.
