이미지 등록 가이드

카페24 파일업로더에서 멤버십 전용 이미지를 등록하거나 교체하는 방법을 안내합니다. 이미지가 연결된 파일명을 그대로 사용해야 페이지에 정상 반영됩니다.

등록 위치 /web/upload/membership/총 11개 이미지·아이콘파일명·확장자 유지 필수
01

이미지 등록 위치 확인

파일업로더 왼쪽 폴더 트리에서 아래 경로로 이동합니다.

ROOT›web›upload›membership
STEP 1

쇼핑몰 관리자에서 파일업로더를 실행합니다.

STEP 2

왼쪽 폴더에서 web → upload → membership 순서대로 선택합니다.

STEP 3

상단 Add Files 버튼 또는 드래그 앤 드롭으로 이미지를 업로드합니다.

파일명 변경 금지 — 아래 이미지 목록의 이름과 확장자(.png, .svg)까지 동일해야 기존 HTML·CSS에서 바로 불러옵니다.

04

멤버십 페이지와 이미지 연결

이미지는 페이지의 HTML 및 연결된 CSS 파일에서 지정한 주소로 표시됩니다.

HTML 이미지

등급 혜택, 버튼 아이콘, 휴대폰 목업, 혜택 카드는 membership.html에서 참조합니다.

CSS 배경 이미지

PC·모바일 상단 비주얼과 이벤트 배경은 membership_page.css에서 참조합니다.

이미지 교체

같은 폴더에 같은 파일명으로 이미지를 교체하면 HTML·CSS 수정 없이 반영할 수 있습니다.

공통 이미지 주소 형식 /web/upload/membership/파일명
예시: /web/upload/membership/main_banner_2.png
05

멤버십 페이지 문구 및 내용 수정 방법

이미지 교체와 달리, 화면에 텍스트로 표시되는 문구는 HTML 파일을 직접 수정해야 합니다.

필수 안내 — 멤버십 페이지는 별도의 문구 관리 기능이 연결되어 있지 않습니다. 제목, 설명, 적립금 안내, 이벤트 유의사항 등 텍스트 변경은 카페24 스마트디자인 편집창의 membership.html 소스에서 직접 수정해야 합니다.
카페24 관리자›디자인›스마트디자인 편집›membership.html

스마트디자인의 파일 목록 또는 검색 기능에서 membership.html을 찾아 열고, 아래 HTML 영역의 텍스트를 수정한 후 저장합니다. 파일의 실제 폴더 위치는 쇼핑몰 스킨 구성에 따라 다를 수 있습니다.

수정 항목HTML에서 찾을 위치수정 가능한 내용
상단 멤버십 문구.membership-hero__textVIP GUIDE, 멤버십 안내 제목, 소개 문구
등급 안내 문구.membership-intro회원 등급 산정 기준과 갱신 안내
혜택 영역 제목·버튼#benefitWrap등급 혜택 제도, 회원가입 버튼 문구
이벤트 타이틀.membership-event__headline무제한 FLEX, 친구 초대 적립금 받기
친구 초대 혜택 문구.membership-event__left초대 안내 및 적립금 금액 설명
추천 링크 영역 문구.membership-invite로그인 전·후 안내, 복사·초대 버튼명
이벤트 유의사항.membership-notices적립금 지급 조건, 이용 기한, 참여 제한 등 안내
01 · 소스 열기

스마트디자인 편집에서 membership.html을 열고 수정할 문구를 검색합니다.

02 · 텍스트만 변경

HTML 태그 내부의 문구를 수정합니다. class, id, module, 링크 및 스크립트용 속성은 임의로 수정하지 않습니다.

03 · 저장 및 확인

저장 후 실제 PC·모바일 페이지를 확인합니다. 영문몰은 해당 몰에 적용된 HTML도 별도로 확인해야 합니다.

문구 수정 예시 · 아래 태그 안의 텍스트만 변경
<h1>멤버십 안내</h1>
<p>회원만을 위한 특별한 혜택을 만나보세요</p>
이미지 안의 글자와 화면 텍스트는 수정 방식이 다릅니다.
등급 혜택 이미지(benefit_notice_pc_01.png / benefit_notice_mo_0.png)나 이벤트 카드 이미지 안에 포함된 문구는 HTML에서 변경되지 않습니다. 이미지 파일을 수정한 뒤 동일한 파일명으로 재업로드해야 합니다.
기능 관련 주의 — 추천 링크 생성·복사·카카오톡 공유 기능은 JavaScript 및 카페24 모듈과 연결됩니다. 텍스트나 적립금 안내를 수정한다고 실제 적립금 지급 설정까지 변경되는 것은 아닙니다. 지급 금액·조건을 변경할 때는 운영 설정을 별도로 확인해야 합니다. 디자인 또는 배치 변경은 membership_page.css, 친구 초대 동작 변경은 membership_page.js 작업이 필요합니다.
06

업로드 전·후 확인사항

이미지가 표시되지 않거나 바뀌지 않을 때 먼저 확인할 항목입니다.

  • 업로드 위치가 ROOT → web → upload → membership인지 확인합니다.
  • 파일명 철자, 대소문자, 숫자, 밑줄(_), 확장자가 기존 파일과 정확히 같은지 확인합니다.
  • PC 및 모바일 전용 이미지가 모두 등록되어 있는지 확인합니다.
  • 기존 이미지를 교체한 뒤에도 이전 이미지가 보이면 브라우저 캐시를 새로고침해 확인합니다.
  • 이미지의 비율이 기존과 크게 다르면 페이지에서 여백 또는 잘림이 생길 수 있으므로 기존 비율에 맞춰 제작합니다.
  • 현재 안내에 포함된 이미지 안의 텍스트·혜택 내용은 이미지 자체를 수정해야 변경됩니다.
별도 확인 — 기존 카카오톡 공유 JS에서 참조했던 thum.png는 첨부 화면의 11개 파일 목록에 보이지 않습니다. 실제 공유 썸네일을 사용하는 경우에는 별도 등록 여부를 확인해 주세요.
