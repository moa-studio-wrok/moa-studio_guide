카페24 관리자

상품 옵션 · 맛 이미지 · 롤링 띠 배너
등록 가이드

구성(10개입, 20개입 …)을 카드로 고르고 맛을 이미지와 함께 선택하는 옵션 화면과,
메인 페이지 롤링 띠 배너를 등록하는 방법입니다.

작업 순서

  1. STEP 1옵션 설정 화면 열기
  2. STEP 2옵션 구성 규칙
  3. STEP 3구성 가격(추가금액)과 라벨
  4. STEP 4맛 옵션값 등록
  5. STEP 5맛 이미지 올리기
  6. STEP 6롤링 띠 배너 등록
1

옵션 설정 화면 열기

상품 수정 화면의 옵션/재고 탭에서 옵션을 등록합니다.

상품 수정 → 옵션/재고 탭

  1. 관리자에서 상품 > 상품목록으로 이동해 옵션을 넣을 상품을 엽니다.
  2. 위쪽 탭에서 옵션/재고를 누릅니다.
  3. 옵션사용은 사용함으로 선택합니다.
  4. 옵션 구성방식은 상품 연동형으로 선택합니다.
  5. 옵션세트 불러오기에서 이 상품용 옵션세트를 선택하면 아래 사용된 옵션 목록이 나타납니다.
꼭 확인해 주세요
· 옵션 구성방식은 상품 연동형이어야 구성 카드와 맛 선택 화면이 정상적으로 동작합니다. 다른 방식(조합 일체/분리, 독립 선택형)으로 등록하면 옵션이 따로 담기거나 가격이 어긋날 수 있습니다.
· 재고관리 사용은 사용안함으로 두세요. 사용함으로 바꾸면 재고수량 0이 품절 처리될 수 있습니다.
2

옵션 구성 규칙

아래 구성대로 옵션을 만들면 쇼핑몰 화면이 자동으로 카드와 맛 선택으로 바뀝니다.

옵션 5개를 이렇게 등록합니다

순서옵션명옵션값 예시옵션 스타일
1플랜 선택10개입 / 20개입 / 30개입 | 🔥 가장 많이 사요 / 40개입 | 💸 최대 할인 구성셀렉트박스
2맛 선택 1번병아리콩, 까만콩, 초코프로틴, 요거트, 선택 안함셀렉트박스
3맛(추가선택) 1번위와 같은 맛 + 선택 안함셀렉트박스
4맛(추가선택) 2번위와 같은 맛 + 선택 안함셀렉트박스
5맛(추가선택) 3번위와 같은 맛 + 선택 안함셀렉트박스
  • 5개 옵션 모두 필수옵션으로 설정합니다.
  • 맛 이미지는 옵션에 올리지 않습니다. 5단계에서 파일로 올립니다.

규칙 4가지

  1. 첫 번째 옵션명에 묶음, 플랜, 구성 중 하나가 들어가야 합니다. (예: 묶음 선택, 플랜 선택) 이 단어가 없는 상품은 기존 옵션 화면이 그대로 나옵니다.
  2. 고르는 맛의 개수는 구성 이름으로 정해집니다.
    구성 이름고르는 맛
    10개입 / 20개입 / 30개입 / 40개입10개당 1개 → 1 / 2 / 3 / 4개
    1주 플랜 / 2주 플랜 …N주 → N개
  3. 맛 옵션 칸의 수는 가장 많이 고르는 개수와 같아야 합니다. 40개입이 맛 4개를 고르니 맛 선택 1번 + 맛(추가선택) 1~3번 = 4칸입니다.
  4. 모든 맛 옵션의 마지막 값에 선택 안함을 넣습니다. 맛을 적게 고르는 구성에서 안 쓰는 칸을 자동으로 채우는 값이며, 쇼핑몰 화면에는 보이지 않습니다.
주의
· 같은 맛은 모든 맛 옵션에서 이름이 완전히 같아야 합니다. 띄어쓰기 하나만 달라도 다른 맛으로 인식됩니다. (예: 제품A와 제품 A는 다름)
· 옵션값을 만들 때 맨 앞이나 뒤에 공백을 넣지 마세요.
3

구성 가격(추가금액)과 라벨

구성 카드에 보이는 가격은 옵션값의 추가금액으로 정해집니다. 할인율 옆 라벨도 여기서 같이 입력합니다.

옵션값 수정에서 추가금액 입력

  1. 옵션/재고 탭의 "사용된 옵션"에서 플랜 선택 줄 오른쪽 옵션값 수정을 누릅니다.
  2. 옵션값 왼쪽의 추가금액 버튼을 누르면 금액 입력칸이 열립니다.
  3. +를 선택하고 금액(KRW)을 입력합니다. 기준이 되는 첫 번째 구성은 0원으로 두면 됩니다.
  4. 저장을 누릅니다.
옵션값추가금액카드 판매가 (상품 판매가 16,200원 기준)
10개입0원16,200원
20개입13,800원30,000원
30개입 | 🔥 가장 많이 사요26,800원43,000원
40개입 | 💸 최대 할인 구성38,500원54,700원
  • 카드 판매가 = 상품 판매가 + 추가금액입니다. 상품 판매가를 바꾸면 추가금액도 다시 계산해 주세요.
  • 카드의 정가(취소선), 할인율, 1개당 가격은 자동으로 계산됩니다. 정가는 상품의 소비자가를 기준으로 구성 개수에 맞춰 계산합니다. 상품 소비자가를 꼭 입력해 주세요.
  • 맛 옵션값의 추가금액은 모두 0원으로 둡니다.

할인율 옆 라벨 (🔥 가장 많이 사요)

옵션값 뒤에 |를 붙이고 문구를 적으면 구성 카드의 할인율 옆에 라벨로 표시됩니다.

입력한 옵션값카드에 보이는 모습
30개입 | 🔥 가장 많이 사요제목 30개입, 할인율 옆 라벨 🔥 가장 많이 사요
40개입|💸 최대 할인 구성제목 40개입, 라벨 💸 최대 할인 구성
10개입제목 10개입, 라벨 없음
  • | 앞뒤 띄어쓰기는 있어도 없어도 됩니다.
  • 라벨이 필요 없는 구성은 이름만 적습니다.
알아두세요
· 라벨은 옵션값 안에 들어가므로 장바구니와 주문서에는 30개입 | 🔥 가장 많이 사요처럼 그대로 표시됩니다. 상품 상세페이지의 선택 결과에서는 라벨이 보이지 않습니다.
· 이모지(🔥 💸)가 저장되는지 처음에 한 번 확인해 주세요.
· 오른쪽 PAPERBAG (영어) 칸은 영문 쇼핑몰용입니다. 영문 쇼핑몰을 쓰지 않으면 신경 쓰지 않아도 됩니다.
4

맛 옵션값 등록

고를 수 있는 맛을 옵션값으로 넣습니다. 맛 옵션 4개에 같은 값을 똑같이 넣어야 합니다.

옵션값 수정에서 맛 입력

  1. 맛 선택 1번 줄 오른쪽 옵션값 수정을 누릅니다.
  2. 위 칸에 옵션명(맛 선택 1번)을 확인하고, 아래에 맛을 한 줄에 하나씩 입력합니다.
  3. 마지막 줄에 선택 안함을 넣습니다. 줄이 부족하면 오른쪽 + 버튼으로 추가합니다.
  4. 저장을 누릅니다.
  5. 맛(추가선택) 1번 · 2번 · 3번도 같은 방법으로 똑같은 맛과 선택 안함을 입력합니다.
맛을 새로 추가할 때
① 맛 옵션 4개(맛 선택 1번, 맛(추가선택) 1~3번) 모두에 같은 이름으로 맛을 추가하고 (선택 안함 앞에 두는 것이 좋습니다)
② 5단계처럼 같은 이름의 이미지를 올리면 됩니다. 스킨 코드를 고칠 필요는 없습니다.
· 같은 옵션세트를 여러 상품이 함께 쓰고 있다면 한 상품의 수정이 다른 상품에도 영향을 줄 수 있으니 확인 후 수정해 주세요.
5

맛 이미지 올리기

맛 이미지는 옵션이 아니라 파일업로더의 정해진 폴더에 올립니다. 파일 이름이 맛 이름과 같으면 자동으로 연결됩니다.

파일업로더 → web / upload / option_thumb

  1. 관리자 왼쪽 메뉴에서 디자인 > 웹 FTP > 파일업로더를 엽니다.
  2. 왼쪽 폴더에서 web > upload > option_thumb 폴더를 선택합니다. 위쪽 경로가 ROOT > web > upload > option_thumb로 보이면 맞습니다.
  3. Add Files를 누르거나, 파일을 위쪽 점선 영역으로 끌어다 놓습니다.
  4. 업로드가 끝나면 아래 목록에 파일이 보입니다.
맛 이름 (옵션값)올릴 파일 이름
병아리콩병아리콩.jpg
까만콩까만콩.jpg
초코프로틴초코프로틴.jpg
요거트요거트.jpg
이미지 규칙
· 파일 이름은 옵션값의 맛 이름과 똑같이, 확장자는 .jpg로 통일합니다. (.png나 .jpeg는 자동으로 연결되지 않습니다)
· 정사각형 이미지를 권장합니다. 목록에는 작은 정사각형 썸네일로 보이니, 한 개당 가벼운 용량(1MB 이하)이 좋습니다.
· 이미지가 없는 맛은 회색 빈 칸으로 보입니다. 오류는 나지 않습니다.
· 이미지를 바꾸려면 같은 이름으로 다시 올린 뒤, 쇼핑몰에서 Ctrl + F5로 새로고침해 확인합니다.
6

메인 롤링 띠 배너 등록

메인 페이지의 글자가 오른쪽에서 왼쪽으로 흐르는 띠는 배너매니저 앱에서 이미지 1장으로 관리합니다.

배너매니저 → 롤링 텍스트 배너

  1. 관리자에서 앱 > 배너매니저를 엽니다.
  2. 배너 그룹 목록에서 롤링 텍스트 배너 - PC&모바일(메인페이지 표시)을 찾습니다.
  3. 오른쪽 수정을 눌러 이미지를 등록합니다.
  4. 오른쪽 스위치가 켜짐(초록색)인지 확인합니다. 끄면 띠가 사라집니다.
  • 띠에 흐르는 문구는 이미지 안에 직접 들어 있습니다. 문구를 바꾸려면 새 이미지를 만들어 교체합니다.
  • 이미지는 1장만 등록해 주세요. 가로 1300px × 세로 54px 정도의 띠 모양이 좋고, 한 장 안에 같은 문구를 여러 번 넣어 두면 자연스럽게 이어집니다.
  • 링크는 넣지 않아도 됩니다.
표시 위치
· PC: 메인 페이지 페럴렉스 배너 바로 아래
· 모바일: 메인 배너 바로 아래
7

쇼핑몰에서 이렇게 보입니다

상품 상세페이지의 옵션 영역 동작입니다.

  • 옵션 영역이 1 묶음 선택 → 2 맛 선택 순서의 접이식 카드로 나옵니다. 머리글을 누르면 접고 펼 수 있습니다.
  • 페이지가 열리면 첫 번째 구성이 미리 선택되어 있고 맛 선택 단계가 펼쳐져 있습니다.
  • 구성 카드에는 할인율, 라벨, 정가, 판매가, 1개당 가격이 보입니다. 다른 카드를 누르면 구성이 바뀝니다.
  • 맛은 이미지 + 이름 + − / + 로 고릅니다. 같은 맛을 여러 번 고를 수 있습니다.
  • 고르는 개수를 다 채우면 자동으로 아래 합계에 담기고, 옵션 영역은 처음 상태로 돌아갑니다.
  • 합계 영역의 선택 결과에는 상품명, 구성, 고른 맛이 카드로 나옵니다. 같은 맛은 병아리콩 ×2처럼 합쳐서 보입니다. 수량 변경과 삭제(×)도 여기서 합니다.
  • 다른 구성을 더 담으려면 구성 카드를 다시 누르면 됩니다.
확인 방법
수정한 뒤 상품 상세페이지에서 Ctrl + F5로 새로고침하면 바로 보입니다. 옵션 구성이 위 규칙과 다르면 기존 카페24 옵션 화면이 그대로 나올 수 있습니다.
8

이럴 땐 이렇게 확인하세요

화면이 기대와 다를 때 먼저 확인할 항목입니다.

증상확인할 것
옵션이 기존 카페24 모양으로 나옴첫 번째 옵션명에 묶음 / 플랜 / 구성이 들어 있는지, 옵션 구성방식이 상품 연동형인지 확인합니다.
맛 이미지가 안 나옴파일 이름이 옵션값의 맛 이름과 같은지, 확장자가 .jpg인지, option_thumb 폴더에 올렸는지 확인합니다.
카드 가격이 모두 같거나 할인율이 없음플랜 옵션값의 추가금액과 상품의 소비자가가 입력되어 있는지 확인합니다.
맛 목록이 비어 있음맛 옵션에 값이 등록되어 있는지, 5개 옵션이 모두 필수로 설정되어 있는지 확인합니다.
담기가 안 됨모든 맛 옵션 마지막에 선택 안함이 있는지, 맛 이름이 옵션마다 똑같은지 확인합니다.
메인 띠가 안 보임배너매니저 롤링 텍스트 배너에 이미지가 1장 등록되어 있고 스위치가 켜져 있는지 확인합니다.
그래도 해결되지 않으면
상품 번호와 증상 화면(캡처)을 함께 알려 주세요. 관리자 메뉴 이름은 계정과 카페24 버전에 따라 조금 다를 수 있습니다.
