수량(박스) 선택 옵션
운영 가이드 v1.0

박스별 단품을 상세페이지 한 곳에서 고르고 바로 이동하도록
옵션을 등록하는 방법과 운영 점검을 안내하는 실무 안내서

카페24 관리자 기준반응형 스킨 · PC·모바일 공통2026. 11. 06
옵션 등록정해진 형식으로 옵션값 입력
상품 연결옵션값 끝에 #상품번호 입력
출시 전 점검선택 · 이동 · 가격 · 모바일
01

개요

고객이 수량을 고르는 흐름을 먼저 이해해 주세요.

박스 수량별로 따로 등록된 단품(1박스, 2박스, 3박스 …)을 상세페이지 상단의 수량 선택 박스로 연결합니다. 고객은 보고 있던 페이지에서 다른 수량을 누르는 즉시 그 수량의 상품 페이지로 이동하고, 이동한 상품의 판매가로 결제합니다.

STEP 1수량 선택 박스에서 수량 클릭
›
STEP 2해당 박스 단품 상세페이지로 이동
›
STEP 3구매하기 · 장바구니 (단독 결제)
표시 요소화면 동작운영 참고
수량 선택 박스가격·배송 정보 아래, 구매 버튼 위에 표시됩니다.PC·모바일 모두 표시됩니다.
현재 수량 표시보고 있는 수량이 파란 테두리와 파란 선택 점으로 표시됩니다.옵션값 중 #상품번호가 현재 상품과 같은 항목이 자동 선택됩니다.
절약 금액 문구“N박스 사면 X원 절약”이 자동 계산되어 표시됩니다.이름의 “N박스”와 1박스 옵션의 판매가를 기준으로 계산합니다.
라벨이름 옆에 추천, 최대할인 같은 라벨이 표시됩니다.옵션값 맨 앞에 [라벨]을 붙이면 됩니다.
결제 금액은 이동한 상품의 판매가

옵션값에 적은 판매가는 화면 표시와 절약 계산용입니다. 실제 결제 금액은 이동한 단품의 판매가로 결정되므로 옵션 추가금액은 입력하지 않습니다.

02

운영 구조

무엇을 어디에서 수정하는지 한 장으로 확인할 수 있습니다.

관리 항목관리 위치운영 방법
수량 옵션상품관리 > 상품수정 > 옵션/재고옵션명 수량에 정해진 형식의 옵션값을 한 줄씩 입력합니다.
연결 상품각 옵션값 끝의 #상품번호그 수량을 눌렀을 때 이동할 상품의 상품번호를 적습니다.
가격 · 절약 금액각 옵션값의 판매가 칸단품 판매가와 같은 값을 숫자 + 원으로 적습니다. 가격이 바뀌면 같이 수정합니다.
수량 선택 박스 모양고객이 보는 상품 상세페이지옵션 저장 후 상세페이지에서 표시와 이동을 확인합니다.
핵심 원칙 — 같은 상품군은 모든 단품에 같은 옵션 세트

1·2·3·4·6박스 단품이 있다면 다섯 상품 모두에 같은 옵션값 목록을 등록합니다. 그래야 어느 단품 페이지로 이동해도 같은 박스가 보이고, 현재 수량이 선택된 상태로 표시됩니다.

03

옵션 등록 방법

실제 관리자 화면을 보면서 순서대로 설정해 주세요.

3-1. 옵션 설정

옵션/재고 탭 열기

수정할 상품을 열고 옵션/재고 탭으로 이동합니다.

상품관리 > 상품수정 > 옵션/재고

옵션 사용 · 구성방식 · 설정 방식 선택

항목설정 값
옵션사용사용함
옵션 구성방식조합 분리선택형
옵션설정직접 입력하기

옵션스타일과 옵션명 입력

항목설정 값참고
옵션스타일라디오버튼다른 스타일이면 수량 선택 박스로 나오지 않습니다.
옵션명수량고객 화면에는 박스 목록만 보입니다.

옵션값 입력

3-2의 형식대로 옵션값을 입력합니다. 값 하나를 입력하고 Enter(또는 Tab, 세미콜론)로 확정하면 다음 값을 입력할 수 있습니다.

‘모든 옵션 품목추가’ 후 저장

모든 옵션 품목추가 버튼을 누르고, 아래 품목 목록에서 옵션 추가금액은 입력하지 않습니다. 마지막으로 화면 아래 상품수정을 눌러 저장합니다.

3-2. 옵션값 입력 형식

옵션값 하나는 슬래시(/)로 칸을 나누어 아래 순서대로 작성합니다. 슬래시는 반드시 넣어야 합니다.

입력 형식[라벨]/이름/판매가/#상품번호
칸필수작성 예설명
라벨선택[추천]맨 앞 칸이며 대괄호 [ ]로 감쌉니다. 쓰지 않으면 칸째 생략합니다.
이름필수3박스(총3개월분)화면에 보이는 이름입니다. “N박스”를 포함해야 절약 금액이 자동 계산됩니다.
판매가필수30360원숫자 + 원. 화면 표시와 절약 계산에만 쓰이며 실제 결제 금액이 아닙니다.
설명선택최근 3개월 판매 1위판매가 뒤에 넣는 짧은 문구입니다. 쓰지 않으면 칸째 생략합니다.
상품번호필수#208이 수량을 누르면 이동할 상품의 상품번호입니다. #으로 시작하고 맨 끝에 둡니다.
입력 예시 · 1·2·3·4·6박스 상품군 (한 줄에 하나씩)1박스(총1개월분)/12100원/#215
2박스(총2개월분)/20350원/#207
[추천]/3박스(총3개월분)/30360원/#208
4박스(총4개월분)/40010원/#209
[최대할인]/6박스(총6개월분)/59290원/#211
  • 현재 보고 있는 상품의 수량도 목록에 포함합니다. 이 예시에서 1박스 상품이 215번이라 #215가 들어 있습니다.
  • 절약 금액은 “1박스 옵션의 판매가 × N − 해당 옵션의 판매가”로 계산됩니다. 예: 2박스 → 12,100 × 2 − 20,350 = 3,850원. 1박스 옵션이 없으면 절약 문구는 나오지 않습니다.
세미콜론(;)은 옵션값에 쓸 수 없습니다.

입력란이 세미콜론을 값의 구분으로 보기 때문입니다. 설명 칸에도 쓰지 않습니다.

같은 상품군의 모든 단품에 옵션 전체를 똑같이 등록해야 합니다.

예시처럼 1·2·3·4·6박스 상품이 있다면 다섯 상품 모두에 위 5줄을 전부 등록합니다. 일부 상품에만 등록하거나 일부 줄이 빠지면, 그 상품 페이지에서는 수량 선택 박스가 나오지 않거나 일부 수량이 목록에서 빠지고, 현재 수량 선택 표시도 되지 않습니다. 상품마다 바뀌는 것은 없고, 옵션값 5줄은 모든 단품에서 동일합니다.

3-3. 상품번호 확인 방법

상품목록 열기

상품 > 상품목록

연결할 단품의 ‘바로구매 URL’ 확인

목록 맨 오른쪽 바로구매 URL 열에서 연결할 상품 행의 주소를 확인합니다. 상품명(박스 수량)으로 행을 찾습니다.

주소 끝의 숫자를 상품번호로 사용

주소의 맨 끝 숫자가 상품번호입니다. 옵션값 끝에 #을 붙여 입력합니다.

예시https://cnsmall.kr/surl/O/211  →  옵션값 끝에 #211

아래 표는 같은 번호를 확인하는 다른 방법입니다.

방법확인 위치예시
상세페이지 주소주소의 product_no= 뒤 숫자…/detail.html?product_no=211 → 211
단축 URL관리자 상품 목록의 단축 URL 끝 숫자https://cnsmall.kr/surl/O/211 → 211
‘지원하지 않는 상품입니다’로 나오는 상품은 연결하지 마세요.

바로구매 URL 칸에 주소 대신 이 문구가 나오는 상품은 진열 상태가 아닐 수 있습니다. 진열 상태를 먼저 확인하고, 진열한 뒤 주소가 나오면 그 번호를 사용합니다.

상품코드는 상품번호가 아닙니다.

상품코드(예: P00000ID)는 옵션값에 쓸 수 없습니다. 반드시 위의 숫자(상품번호)를 적습니다. 상품번호를 잘못 적으면 다른 상품이나 오류 페이지로 이동합니다.

04

고객 화면 동작

운영자는 실제 고객처럼 선택 과정을 확인해 주세요.

고객 행동화면에서 일어나는 일
상세페이지 진입현재 상품의 수량이 선택된 상태로 표시되고, 합계 영역에 현재 수량이 담깁니다.
다른 수량 클릭그 수량의 단품 상세페이지로 바로 이동합니다.
이동한 페이지에서 구매이동한 상품의 판매가로 단독 결제됩니다.
라벨이 있는 수량이름 옆에 라벨이 표시됩니다.
2박스 이상 수량“N박스 사면 X원 절약”이 표시됩니다. (1박스 옵션이 있을 때)
PC·모바일같은 스킨을 사용하므로 모두 같은 방식으로 동작합니다.
수량 선택선택 표시 · 이동

현재 수량 선택 표시와 다른 수량 클릭 시 이동을 확인합니다.

가격 · 문구가격 · 절약 · 라벨

가격이 단품 판매가와 같은지, 절약 문구와 라벨이 맞는지 확인합니다.

05

적용 · 운영 점검

다른 상품에 적용하거나 수정한 뒤에는 아래를 확인해 주세요.

다른 상품에 적용하는 순서

  1. 연결할 박스별 단품이 모두 진열 상태인지 확인합니다.
  2. 단품마다 상품번호를 확인해 두고, 판매가를 표로 정리합니다.
  3. 한 상품에 3장의 형식대로 옵션을 등록합니다.
  4. 같은 옵션값 목록을 같은 상품군의 다른 모든 단품에도 등록합니다.
  5. 각 상품 상세페이지에서 현재 수량 선택과 이동을 확인합니다.
진열하지 않은 상품의 번호는 넣지 마세요.

진열 상태가 아니면 고객이 눌렀을 때 오류 페이지가 뜹니다. 예를 들어 관리자 목록의 단축 URL이 “지원하지 않는 상품입니다”로 나오는 상품은 먼저 상태를 확인합니다.

확인 링크 (복사본 디자인 skin20)

구분상품번호확인 링크
수량 옵션 테스트 상품 (1박스 · 현재 215)215https://cnshc.cafe24.com/skin-skin20/product/detail.html?product_no=215

위 링크는 복사본 디자인(skin20) 주소입니다. 운영 쇼핑몰에 반영되면 주소가 바뀌므로, 반영 후에는 일반 상품 주소로 확인해 주세요.

06

문제 해결 · FAQ

오류가 보이면 증상부터 확인해 주세요.

증상가능한 원인조치 방법
수량 박스 모양으로 나오지 않고 기본 옵션처럼 보입니다.옵션스타일이 라디오버튼이 아니거나, 옵션값에 #상품번호가 없음옵션스타일과 옵션값 끝의 #상품번호를 확인합니다.
눌러도 이동하지 않거나 엉뚱한 상품으로 갑니다.#상품번호를 잘못 적음 (상품코드를 적은 경우 포함)상품 주소의 product_no 숫자로 다시 입력합니다.
눌렀더니 오류 페이지가 뜹니다.연결한 상품이 진열 상태가 아님연결 상품의 진열·판매 상태를 확인하고 진열합니다.
절약 금액이 나오지 않습니다.이름에 “N박스”가 없거나, 1박스 옵션이 목록에 없음, 판매가 형식 오류이름·1박스 옵션·판매가(숫자+원)를 확인합니다.
이동한 페이지에서 현재 수량이 선택되지 않습니다.그 상품에 같은 옵션이 등록되지 않았거나 자기 번호가 없음같은 옵션값 목록을 그 상품에도 등록합니다.
옵션값이 이상하게 나뉘어 들어갑니다.옵션값에 세미콜론(;) 사용세미콜론을 빼고 다시 입력합니다.
라벨이 표시되지 않습니다.대괄호가 없거나 맨 앞 칸이 아님[라벨]을 맨 앞에 대괄호로 감싸 입력합니다.
가격을 바꿨는데 박스의 가격이 그대로입니다.옵션값의 숫자를 고치지 않음옵션값의 판매가 숫자도 같이 수정합니다.
수정 직후 화면이 그대로입니다.캐시(이전 화면을 임시 저장하는 기능) 영향 가능성몇 분 뒤 Ctrl + F5로 강력 새로고침합니다.
